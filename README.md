# ウレシラセ — 追熟ダッシュボード

おおくまハッカソン 2026(株式会社 ReFruits のキウイ在庫・受注管理)向けの、動くモック。
並走する追熟ロットと注文を1本のタイムラインに載せ、今日やることを逆算して出す。


## 動かす

```bash
pnpm install
pnpm dev
```

- `?today=2026-09-02` で「今日」を固定できる(デモ用。現在時刻は 8:30 とみなす)
- `?view=order` で注文別の表示から開く
- 操作(開始した・抜いた・チェック・充てる・出荷)はブラウザに保存される。「最初の状態に戻す」で消える

## 設計の要点

- **段階は入力しない**。ロットは開始日時だけ持ち、エチレン中→寝かせ中→チェック待ち→出荷可能(生食)→加工へ→期限切れ は品種マスタと現在時刻から導く
- **人が入れるのは4つのイベントと例外だけ**。注文・入荷・追熟開始・出荷が入力で、「もう1日」「加工に回した」「廃棄した」が例外
- **期限は2段**。生食期限を過ぎても加工期限まで加工向け注文に充てられる。廃棄は加工期限も過ぎたものだけ
- **入口は問わない**。画面・Google Form・LINE・音声・AI、どこから入っても上の4イベントに落ちれば線が引ける

## 構成

```
src/domain/   型・品種マスタ・時間・導出ロジック・状態(localStorage)
src/data/     ダミーデータ(今日からの相対日付)
src/components/  今日やること / タイムライン / 冷蔵在庫 / 在庫の見通し
```
